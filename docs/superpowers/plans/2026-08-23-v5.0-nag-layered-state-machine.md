# V5.0-V13 NAG Layered State Machine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 V4.9-V13 自适应 NAG 改为预防周期、H2 跟踪和纠正周期互不覆盖的分层状态机，并实现纠正正负帧数 `0` 关闭方向的完整行为。

**Architecture:** 保留现有单控制器和 CAN Echo 链，只在 `NagAdaptiveController` 内分离三个计时所有者。配置、NVS、API、UI 和诊断沿现有字段扩展，不引入新任务、线程、驱动或 CAN 报文。

**Tech Stack:** ESP32-S3、ESP-IDF 6、PlatformIO、C++17、Unity Native Test、Python unittest、静态 HTML/JavaScript dashboard。

**Spec:** `docs/superpowers/specs/2026-08-23-v5.0-nag-layered-state-machine-design.md`

## Global Constraints

- 基线必须是远端 `V4.9-V13` 提交 `d7e27cb004e79a3761b9997ffde9ac01481b36f6`。
- 分支名和内部版本分别为 `V5.0-V13`、`V5.0 V13`。
- 只修改自适应控制器、配置/NVS/API、NAG UI/诊断、版本文档和对应测试。
- Counter+1、每个合格 OEM 0x370 最多一次即时 Echo、CAN 驱动和过滤保持不变。
- 默认设置保持 V4.9 截图数值。
