# WIFI-NAG V1.0.3 随机扫动时间实施计划

## 已确认行为

- 固件仍只发送 `0x370 / 880` Nag echo，不增加 CAN 优先级队列。
- CAN Write 从关闭切换为开启后，收到下一帧真实 `0x370` 时立即写入一次。
- 每次写入完成后，在配置的最短与最长时间之间重新生成一个随机等待时间。
- 默认范围为 `5–8 秒`，允许设置 `1–30 秒`；填反后自动交换，越界值自动限制。
- 等待期间收到的帧不累计、不补发；到期后使用当时最新收到的真实帧写入。
- A 模式保持固定 `+1.80 Nm`。
- A_V2 保持“随机扭矩”，只在实际写入时生成新的范围内随机扭矩，不再使用独立固定的 2000 ms 扫动周期。
- 扫动时间保存在 NVS，重启和固件更新后保留。
