# WiFi-NAG V1.0.3 UI Main-Chain Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the iframe/BLE/sweep runtime composition chain with one generated WiFi-NAG dashboard page returned directly from `/`, while preserving every backend feature API.

**Architecture:** `mcp2515_dashboard_ui.src.h` becomes the sole editable page source and contains the header, four main cards, NAG sweep UI, and BLE UI. `NagSweepWebServer` and `bridge_webui.h` become API-only integrations; `mcp2515_dashboard.h` owns the only root route and redirects legacy page URLs. `minify_dashboard.py` produces the only gzip payload and can verify that the checked-in generated header is current.

**Tech Stack:** ESP32-S3 C++/Arduino-compatible WebServer, embedded HTML/CSS/ES2020 JavaScript, Python 3 `unittest`, PlatformIO native tests, PlatformIO ESP32 firmware build.

## Global Constraints

- Keep firmware version and release metadata at `V1.0.3`.
- Keep BLE API routes exactly `/ble_status`, `/ble_config`, `/ble_pair`, `/ble_unbind`, `/config`, and `/disable`.
- Keep NAG sweep API route exactly `/api/nag-sweep`, with 1–30 second limits and 5–8 second defaults.
- Keep `localStorage.theme` and `localStorage.themeMode` as the theme state keys.
- Keep `mcp2515_dashboard_ui.src.h` as the only editable UI source and `mcp2515_dashboard_ui.base.h` as generated output.
- Do not change BLE protocol, pairing, binding, obstacle forwarding, NAG authority, Wi-Fi, gateway, DNS, logging, OTA, or CAN behavior.
- A local API failure must not replace `body`, write a new document, or reload the dashboard.
- `/dashboard` and `/legacy-dashboard` must remain reachable only as no-cache 302 redirects to `/`.

```python
def extract_section(html: str, element_id: str) -> str:
    start = re.search(
        rf'<section\b[^>]*\bid=(?:"{re.escape(element_id)}"|{re.escape(element_id)}\b)[^>]*>',
        html,
        re.IGNORECASE,
    )
    if start is None:
        raise AssertionError(f"section not found: {element_id}")
    depth = 0
    for tag in re.finditer(r"</?section\b[^>]*>", html[start.start():], re.IGNORECASE):
        depth += -1 if tag.group(0).startswith("</") else 1
        if depth == 0:
            return html[start.start(): start.start() + tag.end()]
    raise AssertionError(f"section is not closed: {element_id}")
```
