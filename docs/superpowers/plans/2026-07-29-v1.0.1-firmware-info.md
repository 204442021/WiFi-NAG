# WiFi-NAG V1.0.1 Firmware Info Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在固件更新卡片显示 `V1.0.1`、当前 OTA 分区和最近一次成功 OTA 的浏览器本地上传时间，并把二进制内部版本统一为 `V1.0.1`。

**Architecture:** 以根目录 `VERSION` 为唯一版本源，同时驱动 `FIRMWARE_VERSION` 和 ESP-IDF `PROJECT_VER`。后端从 ESP-IDF 读取运行分区，成功 OTA 后将浏览器传入的本地时间写入 NVS；现有 `/system_status` 接口一次性向页面提供三项数据。

**Tech Stack:** ESP-IDF 5.x、PlatformIO、C++17、内嵌 HTML/JavaScript、Python unittest。

## Global Constraints

- 目标分支固定为 `V1.0.1`。
- 版本字符串固定为 `V1.0.1`，不得保留 `3.0.0-beta.5`。
- 页面只新增：固件版本、当前分区、OTA 上传时间。
- OTA 时间格式固定为浏览器本地 `YYYY-MM-DD HH:mm:ss`。
- 仅在 `Update.end(true)` 成功且镜像完成时保存时间。
- 不增加在线 OTA、OTA 次数、启动次数、Git Commit 或其他版本字段。
