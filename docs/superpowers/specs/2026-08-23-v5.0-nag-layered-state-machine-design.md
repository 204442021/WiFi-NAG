# V5.0-V13 NAG 分层状态机设计

## 目标

在不修改 CAN 驱动、过滤器、Counter+1 Echo、BLE、网络和 OTA 架构的前提下，修复 V4.9-V13 中预防周期、H2 持续检测和纠正周期共用 `phase_` 计时导致的互相覆盖，并明确纠正正负帧数为 `0` 时的行为。

## 已确认行为

- 远端 `V4.9-V13` 是唯一基线，内部版本递进为 `V5.0 V13`。
- 预防注入/停发周期拥有独立计时；短暂 H2 不得打断预防停发，也不得重启预防注入窗口。
- H2 仅是并行持续计时器。H0/H1 清除 H2 累计；H2 达到阈值后进入纠正前停发；H3-H5 立即进入纠正前停发；H6 以上保护停发。
- 纠正发送/停发拥有独立计时。纠正停发不清空当前正负方向、成功帧位置和峰值，恢复后从原位置继续。
- 正负纠正帧数允许的有效值是 `0` 或 `10..255`：
  - 负=0、正>0：固定正方向循环；
  - 负>0、正=0：固定负方向循环；
  - 两边>0：首方向取方向盘保留方向，随后独立交替；
  - 两边=0：纠正层保持监控但不发送纠正扭矩。
- 单方向模式不经过另一方向，也不执行换向过渡。
- 每一侧的正式纠正帧都在该侧设置的最小值与随机峰值之间，轨迹为最小值→峰值→最小值；最小值等于最大值时固定输出。
- 双方向换向使用固定内部过渡，不占用正负方向帧数；诊断必须能区分正式纠正帧与换向过渡。
- 帧位置只在本地 Echo 成功后推进；发送失败、纠正停发和方向盘绝对角度大于 50° 时冻结。
- 方向盘中心 `±1°` 内保留上一次有效方向，绝对角度大于 `50°` 停止发送但不重置周期。
- 默认参数保持用户截图中的 V4.9 值：预防 `1.50..1.80 Nm`、纠正 `1.80..2.40 Nm`、正负各 100 帧、预防 `2..3 s / 0 s`、H2 `3 s`、纠正前停发 `1 s`、纠正发送 `3 s`、纠正停发 `1..2 s`、稳定确认 `5 s`。

## 状态所有权

- 主阶段 `phase_`：等待 DAS、三帧武装、预防层、纠正前停发、纠正发送、纠正停发、稳定确认、故障保护。
- 预防层：使用自己的活动/停发阶段与起始时间，不由 H2 观察直接改写。
- H2 跟踪器：使用 `h2Tracking` 与 `h2StartedAtMs`，只决定是否升级到纠正。
- 纠正扫动器：保存方向、正式帧位置、峰值和换向过渡位置；纠正停发只暂停，不清空。

## UI 与诊断

- 正负帧数输入允许 `0`，并显示“0 表示关闭该方向”。
- 关闭某一方向时，其扭矩范围控件变灰；两边都为 0 时显示纠正层停发警告。
- 状态区分别显示主阶段、预防子状态/剩余时间、H2 累计/阈值、纠正模式、当前方向/帧位/峰值、换向过渡、下一目标和最近实际发送。
- 删除与当前逻辑冲突或重复的说明，不恢复 Late Echo 和最小发送间隔。

## 修改边界

允许修改自适应控制器、配置校验、NVS/API、NAG UI/诊断、版本文档和对应测试。禁止修改 CAN 驱动、0x370 Counter+1 发送方式、硬件过滤、BLE、网络、OTA、分区和其他业务功能。
